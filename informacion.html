Información acerca de los inputs usados

Esta es la información de los inputs usados en el formulario.

  • Inicio
  • Formulario
  • Información inputs
Tipo de input Uso Información
text Nombre Permite ingresar texto corto
tel Número Para ingresar el teléfono
file Cédula Permite al usuario seleccionar y subir archivos desde su dispositivo
radio Estado civil Permite elegir una sola opción entre varias
email Correo Valida automáticamente que el formato sea un correo electrónico
password Contraseña Oculta los caracteres ingresados por seguridad
date Fecha Muestra un selector de calendario para elegir fechas
color Color favorito Permite al usuario escoger su color favorito
range Satisfacción Barra deslizante para seleccionar un valor dentro de un rango
checkbox Términos Permite activar o desactivar una opción
submit Enviar formulario Permite enviar el formulario mediante un botón
reset Limpiar formulario Permite limpiar todos los campos del formulario mediante un botón
